## Scope

This Functional Requirements Document specifies the exact behavior of each feature in the Simple Request Tracker (SRT) application. It defines inputs, outputs, validation rules, error handling, database schema, and API contracts required for implementation. Developers should be able to implement any feature from this document without ambiguity.

SRT is a two-screen web application: a request submission form and a request list view. It uses a React + Vite + TypeScript frontend communicating via REST API to a Java Spring Boot backend backed by an H2 in-memory database. All features are P0 (critical path). No authentication, pagination, or external services are in scope.

## Cross-Cutting Terminology

| Term | Definition |
|------|-----------|
| **Request** | A user-submitted record containing a name, title, and description. The core domain object of SRT. |
| **Requester** | A business user who submits requests via the web form. |
| **Viewer** | An internal stakeholder who reads the list of all submitted requests. |
| **H2** | H2 in-memory database embedded in the Spring Boot JVM process. Data is lost on restart by design. |
| **JPA** | Java Persistence API — the ORM layer used to map the `Request` entity to H2 tables. |
| **Hibernate DDL** | Hibernate's automatic schema generation (`create-drop`) that creates and drops the `requests` table on startup/shutdown. |
| **CORS** | Cross-Origin Resource Sharing — HTTP headers that allow the React frontend (running on a different port) to call the Spring Boot backend. |
| **Vite dev server** | The Node.js development server that serves the React app, typically on `http://localhost:5173`. |
| **Backend origin** | The Spring Boot server, typically `http://localhost:8080`. |
| **Frontend origin** | The Vite dev server, typically `http://localhost:5173`. |
| **Empty state** | The UI condition when no `Request` records exist in the database. |
| **Required field** | A form field or payload field that must be present and non-blank. Validation fails if missing or whitespace-only. |
